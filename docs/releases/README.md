# Release notes

Each version has a reviewed `<version>.md` file before its annotated tag is
created. The tag message and GitHub Release body originate from this file.

`0.1.0-beta.2.md` documents the second beta preview and its expanded installer
formats. `0.1.0-beta.1.md` remains the first preview's immutable notes. The
`0.1.0.md` file remains a draft for the first stable release.
