# Release notes

Each version has a reviewed `<version>.md` file before its annotated tag is
created. The tag message and GitHub Release body originate from this file. Starting
with 0.2.0, every release note uses concise Chinese and English sections with clear
Markdown headings and matching key points.

`0.2.0.md` documents startup and tray preferences, Traditional Chinese, and the
Go security update in both languages. `0.1.0.md` documents the first stable release. `0.1.0-beta.3.md` documents the
third beta preview with four interface languages, selectable engines, update
management, and editor preferences. `0.1.0-beta.2.md` documents the expanded
installer formats. `0.1.0-beta.1.md` remains the first preview's immutable notes.
