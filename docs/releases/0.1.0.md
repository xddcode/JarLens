# JarLens 0.1.0

JarLens 0.1.0 is the first stable release of the native Java decompiler and code
explorer. It includes the complete beta feature set, four interface languages,
three built-in decompiler engines, update management, and the editor and startup
fixes verified during the preview cycle.

## Highlights

- Open JAR and standalone Class files through a dialog, drag and drop, or a
  command-line argument, and browse lazy package and class trees.
- Decompile with Vineflower 1.12.0, CFR 0.152, or Procyon 0.6.0, with persistent
  engine selection, cancellation, diagnostics, and source export.
- Use Simplified Chinese, English, Japanese, or Korean, with immediate language
  switching and persistent preferences.
- Check stable releases and read release notes from the default official source
  or CNB, with optional automatic checks and no automatic installation.
- Choose Dark, Light, or Follow System appearance.
- Use multiple documents, independently splittable editor panes, project filter,
  source find, nested-class navigation, and go to line.
- Reindent displayed source with Compact (2), Default (4), or Relaxed (6)
  presets, independently toggle indentation guides, and choose the Java
  executable through a native file picker.
- Read XML, JSON, YAML, Manifest, Properties, and other UTF-8/UTF-16 resources.

## Distribution

- Standard zip and tar.gz packages include a managed Adoptium Temurin JRE 21 and
  work without a system Java installation.
- Portable archives and installers use Java 11+ on `PATH` or `JARLENS_JAVA`.
- Windows, macOS, and Linux packages cover amd64 (x64) and arm64, with portable
  `setup.exe`, `dmg`, and `deb` formats where supported.
- The release includes SHA-256 checksums, a source dependency SBOM, license
  notices, and third-party notices.
- Packages are unsigned. Windows SmartScreen and macOS Gatekeeper may warn.

## Runtime and dependency versions

- Go 1.26.10 builds the application and includes current standard-library security fixes.
- Viva 0.5.1 provides native rendering, text measurement, input, and components.
- Vineflower 1.12.0, CFR 0.152, and Procyon 0.6.0 are embedded with their
  original licenses and checksum verification.

## Upgrade notes

- Existing `settings.json` preferences from preview releases require no manual
  migration. New language, update, and editor preferences use documented defaults.
- Read the usage and legal notice in the README before analyzing artifacts.
  Decompiled output remains approximate and may still be subject to the original
  software's copyright and license.

## Verification

- `make check` covers formatting, module tidiness, vet, staticcheck, and tests.
- Full race-detector and real JDK integration tests cover all three engines.
- Windows, macOS, and Linux CI checks cover startup, UI behavior, and release builds.
- GitHub Actions builds and verifies the complete standard and portable package
  matrix before publication.

## Known limitations

- Global source indexing, multi-engine comparison, AI analysis, JAR version diff,
  and Android artifacts are not included.
- Native macOS and Linux product verification remains more limited than Windows;
  platform-specific feedback is welcome.
- Decompiled output is approximate and is not the original source code.
