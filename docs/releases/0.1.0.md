# JarLens 0.1.0

Draft release notes for the first useful JarLens release.

## Required before tagging

- JAR and standalone Class opening.
- Lazy package and class navigation.
- One pinned decompiler engine with source viewing and export.
- Structured diagnostics and task cancellation.
- End-to-end open/decompile/read verification.
- Final platform compatibility and known-limitations section.

The current M0 workspace alone does not satisfy these release criteria.
