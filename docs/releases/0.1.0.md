# JarLens 0.1.0

Draft release notes for the first useful JarLens release.

## Highlights

- Open JAR and standalone Class files through a dialog, drag and drop, or a
  command-line argument.
- Browse lazy package and class trees, including nested-class navigation.
- Decompile with the embedded Vineflower 1.12.0 engine, with cancellation,
  diagnostics, and original-name source export.
- Open multiple documents with independent editor state and close actions.
- Read XML, JSON, YAML, Manifest, and other UTF-8/UTF-16 text resources.
- Filter the project tree, find text in source, navigate matches, and go to line.
- Use Islands Dark or Islands Light themes, a custom titlebar, compact icons, and
  an adjustable project/editor splitter.

## Distribution

- Standard packages include a pinned JRE and work without a system Java install.
- Portable packages use Java 11+ on `PATH` or `JARLENS_JAVA`.
- Checksums, a source dependency SBOM, and third-party notices are included.
- Packages are unsigned at this stage; platform warnings are documented.

## Known limitations

- Global source indexing, multi-engine comparison, AI analysis, JAR version diff,
  and Android artifacts are not included.
- Native macOS and Linux product verification is required before the final tag.
- Decompiled output is approximate and is not the original source code.
