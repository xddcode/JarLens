# JarLens 0.1.0-beta.3

This third beta preview adds four interface languages, selectable decompiler
engines, update management, and more configurable editor behavior. It is a
prerelease intended for evaluation and feedback, not the latest stable version.

## New in this preview

- Choose Simplified Chinese, English, Japanese, or Korean as the interface
  language. Changes apply immediately and persist across restarts.
- Select Vineflower 1.12.0, CFR 0.152, or Procyon 0.6.0 for subsequent
  decompilation, with accurate engine provenance for each document.
- Check stable releases and read release notes from the default official source
  or CNB. Automatic checks can be disabled and no package is installed
  automatically.
- Follow the operating-system appearance, or explicitly choose Dark or Light.
- Reindent displayed source with fixed Compact (2), Default (4), or Relaxed (6)
  presets and independently show or hide indentation guides.
- Use the refreshed JarLens application icon and OpenIDEA refresh glyph.

## Editor and interaction fixes

- Close settings selects when clicking anywhere outside them.
- Finish source drag selection correctly before following class links.
- Keep the decompiler banner inset with rounded corners instead of stretching it
  across the editor.
- Preserve standard clipboard and link-navigation behavior in the source editor.

## Packages and mirroring

- Standard zip and tar.gz packages include a managed JRE and work without a
  system Java installation.
- Portable archives and installers use Java 11+ on `PATH` or an explicit
  `JARLENS_JAVA` path.
- Windows, macOS, and Linux packages cover amd64 (x64) and arm64, with portable
  `setup.exe`, `dmg`, and `deb` formats where supported.
- GitHub Actions mirrors branches and tags to CNB and synchronizes the published
  Release notes and assets through the pinned, checksum-verified `mpgrm` tool.

## Runtime and dependency versions

- Viva 0.5.1 provides native rendering, text measurement, input, and components.
- Vineflower 1.12.0, CFR 0.152, and Procyon 0.6.0 are embedded with their
  original licenses and checksum verification.
- Standard packages include Adoptium Temurin JRE 21; portable packages use Java
  11+ supplied by the user.
- The release includes SHA-256 checksums, a source dependency SBOM, license
  notices, and third-party notices.

## Upgrade notes

- This preview replaces v0.1.0-beta.2 without changing its published assets.
- Existing `settings.json` preferences require no manual migration. New language,
  update, and editor preferences use their documented defaults.
- Packages are unsigned. Windows SmartScreen and macOS Gatekeeper may warn.

## Verification

- `make check` covers formatting, module tidiness, vet, staticcheck, and tests.
- Race-detector tests cover UI behavior, settings, and package behavior.
- Real JDK integration tests cover all three decompiler engines.
- GitHub Actions builds and verifies the complete standard and portable package
  matrix before publishing this prerelease.

## Known limitations

- Global source indexing, multi-engine comparison, AI analysis, JAR version diff,
  and Android artifacts are not included.
- Native macOS and Linux product verification is still required before a stable
  release; the preview does not claim production verification on those systems.
- Decompiled output is approximate and is not the original source code.
