# JarLens 0.1.0-beta.1

This is the first beta preview of JarLens, a native Java decompiler and code
explorer. It is intended for evaluation and feedback rather than production
migration. The GitHub Release is marked as a prerelease, not as latest stable.

## Highlights

- Open JAR and standalone Class files through a dialog, drag and drop, or a
  command-line argument, and browse lazy package and class trees.
- Decompile with the embedded Vineflower 1.12.0 engine, with cancellation,
  diagnostics, and original-name source export.
- Open multiple documents in independently splittable editor panes, with nested
  class navigation, source search, match navigation, and go to line.
- Read XML, JSON, YAML, Manifest, Properties, and other UTF-8/UTF-16 resources.
- Use the OpenIDEA-inspired workbench with Islands Dark and Islands Light,
  default OpenIDEA file and toolbar icons, and adjustable project/editor panes.
- Configure the application through an OpenIDEA-style settings page tree with
  search, back/forward history, per-page reset, staged changes, and persistent
  appearance, editor, Java, and startup preferences.

## Runtime and dependency versions

- Viva 0.5.1 provides native rendering, text measurement, input, and components.
- Vineflower 1.12.0 is embedded as an unmodified Apache-2.0 artifact.
- Standard packages include Adoptium Temurin JRE 21 and work without a system
  Java installation.
- Portable packages use Java 11+ on `PATH` or an explicit `JARLENS_JAVA` path.
- Checksums, a source dependency SBOM, and third-party notices are included.

## Upgrade notes

- Replace earlier development builds rather than running both versions side by
  side; this preview upgrades the Viva dependency to 0.5.1 and uses the revised
  settings interface.
- Existing settings remain in `settings.json` in the user configuration
  directory. No manual settings migration is required.
- Packages are unsigned at this stage. Operating-system warnings may appear.

## Verification

- `make check` covers formatting, module tidiness, vet, staticcheck, and tests.
- `go test -race ./internal/ui -count=1` covers the UI with the race detector.
- GitHub Actions runs headless tests and release builds on Windows, macOS, and
  Linux, real JDK integration tests, and the complete packaging matrix before
  publication.

## Known limitations

- Global source indexing, multi-engine comparison, AI analysis, JAR version
  diff, and Android artifacts are not included.
- Native macOS and Linux product verification is still required before a stable
  release. This preview must not claim those platforms are production-verified.
- Decompiled output is approximate and is not the original source code.
