# JarLens 0.1.0-beta.2

This second beta preview keeps the JarLens 0.1.0-beta.1 workbench and adds clearer
installer choices for Windows, macOS, and Linux. It is a prerelease intended for
evaluation and feedback, not the latest stable version.

## New in this preview

- Portable Windows packages include an NSIS `setup.exe` installer as well as a
  zip archive for each supported architecture.
- Portable macOS packages include a `dmg` disk image as well as a zip archive.
- Portable Linux packages include a `deb` package as well as a tar.gz archive.
- File names identify the platform, `amd64` (x64) or `arm64` architecture,
  `portable` variant, and package format explicitly.
- Standard zip and tar.gz packages still bundle the managed JRE and work without
  a system Java installation.

Portable installers and archives use Java 11+ on `PATH` or an explicit
`JARLENS_JAVA` path. Choose a standard archive instead when Java is not installed.

## Existing capabilities

- Open JAR and standalone Class files, browse package and class trees, and
  decompile with the embedded Vineflower 1.12.0 engine.
- Use multiple documents and independently splittable editor panes, source
  search, nested-class navigation, and go to line.
- Read XML, JSON, YAML, Manifest, Properties, and other UTF-8/UTF-16 resources.
- Use the OpenIDEA-inspired workbench, Islands Dark and Islands Light, default
  OpenIDEA icons, and persistent searchable settings.

## Runtime and dependency versions

- Viva 0.5.1 provides native rendering, text measurement, input, and components.
- Vineflower 1.12.0 is embedded as an unmodified Apache-2.0 artifact.
- Standard packages include Adoptium Temurin JRE 21; portable packages use Java
  11+ supplied by the user.
- The release includes SHA-256 checksums, a source dependency SBOM, license
  notices, and third-party notices.

## Upgrade notes

- This preview replaces v0.1.0-beta.1 without changing its published assets.
- Existing `settings.json` preferences require no manual migration.
- Packages are unsigned. Windows SmartScreen and macOS Gatekeeper may warn.

## Verification

- `make check` covers formatting, module tidiness, vet, staticcheck, and tests.
- `go test -race -p 1 ./... -count=1` covers the race detector across packages.
- Real JDK integration tests and runtime packaging tests pass before release.
- GitHub Actions builds and verifies the complete standard and portable package
  matrix, including every installer format, before publishing this prerelease.

## Known limitations

- Global source indexing, multi-engine comparison, AI analysis, JAR version diff,
  and Android artifacts are not included.
- Native macOS and Linux product verification is still required before a stable
  release; the preview does not claim production verification on those systems.
- Standard installer-specific formats are not provided yet because the current
  bundler must preserve the complete managed JRE in every offline package.
- Decompiled output is approximate and is not the original source code.
