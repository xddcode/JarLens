# JarLens 0.2.0

## 中文

本次版本新增启动与托盘偏好设置、繁体中文界面，并包含 Go 标准库安全修复。

### 重点更新

- 启动时可选择恢复最近项目或回到 Home。
- 关闭窗口时可选择直接退出或最小化到托盘，托盘菜单支持打开和退出。
- 支持当前用户登录时自动启动，适用于 Windows、macOS 和 Linux。
- 新增繁体中文，完整覆盖界面、设置搜索、更新和状态提示。
- 最低构建版本升级为 Go 1.26.11，修复 `GO-2026-6859`。

### 升级说明

- 现有设置自动保留；新偏好使用默认值，无需手动迁移。
- 开机自动启动默认关闭，启用并保存后才会写入当前用户启动配置。
- 应用内更新仅检查版本并打开下载页，不会自动下载或安装。

### 已知限制

- 开机自动启动和托盘行为已覆盖自动化测试，真实登录及原生托盘验证仍有限。
- macOS 和 Linux 的原生产品验证少于 Windows。

## English

This release adds startup and tray preferences, Traditional Chinese localization,
and a Go standard-library security fix.

### Highlights

- Restore the recent project or return to Home on startup.
- Exit directly or hide to the tray when closing the window, with tray Open and
  Quit actions.
- Launch at login for the current user on Windows, macOS, and Linux.
- Use Traditional Chinese across the interface, settings search, updates, and
  status messages.
- Require Go 1.26.11 or newer to include the fix for `GO-2026-6859`.

### Upgrade notes

- Existing settings are preserved and new preferences use their defaults; no
  manual migration is required.
- Launch at login is off by default and changes the current user's startup
  configuration only after it is enabled and saved.
- In-app updates only check versions and open the download page; packages are
  never downloaded or installed automatically.

### Known limitations

- Automated tests cover launch-at-login and tray behavior, but real login and
  native tray verification remains limited.
- Native macOS and Linux product verification remains more limited than Windows.
