# JarLens 0.2.1

## 中文

本次版本带来 Windows 一键自动更新，支持 GitHub 和 CNB 两种下载源，并改进更新说明排版。

### 重点更新

- 用户级 Windows 安装支持“立即更新”：显示下载进度、可取消、校验后静默安装并重启。
- GitHub 和 CNB 均可完成检查、签名验证、安装包下载和安装，下载地址跟随所选来源。
- 更新包使用 Ed25519 签名和 SHA-256 双重校验，安装前再次验证。
- 发布说明使用 Markdown 渲染，不再显示原始标记。
- 开发版、便携版、系统级安装及其他平台保留手动下载，并说明原因。

### 升级说明

- 0.1.0 和 0.2.0 不含自动更新器，需要手动下载并安装一次 0.2.1。
- 从 0.2.1 开始，后续版本可直接在应用内更新。
- CNB 自动更新需等待 Release 及签名清单同步完成；未完成时可先使用 GitHub 或手动下载。

### 构建与验证

- Go 1.26.11、Viva 0.5.1；内置 Vineflower 1.12.0、CFR 0.152 和 Procyon 0.6.0。
- 标准版包含 Temurin JRE 21；便携版使用 Java 11+。
- 完整质量、竞态、集成、安全、真实更新进程及三平台构建检查通过。
- 发布包未签名，Windows SmartScreen 和 macOS Gatekeeper 可能提示警告。

## English

This release adds one-click Windows updates through GitHub or CNB, plus properly
rendered release notes.

### Highlights

- Update registered per-user Windows installations in place, with progress,
  cancellation, verification, silent installation, and restart.
- Use GitHub or CNB for release checks, signature verification, package downloads,
  and installation, all through the selected source.
- Verify every package with an Ed25519-signed feed and SHA-256, including a second
  check immediately before installation.
- Render release notes as Markdown instead of literal markup.
- Keep manual downloads for development, portable, system-wide, and non-Windows
  installations, with a clear explanation.

### Upgrade notes

- Versions 0.1.0 and 0.2.0 do not include the updater, so install 0.2.1 manually
  once. Later updates can be installed directly in the app.
- CNB updates become available after its release and signed-feed synchronization
  finishes. Use GitHub or manual download until then.

### Build and verification

- Go 1.26.11 and Viva 0.5.1; embedded Vineflower 1.12.0, CFR 0.152, and Procyon
  0.6.0.
- Standard packages include Temurin JRE 21; portable packages use Java 11+.
- Quality, race, integration, security, real update-process, and three-platform
  build checks pass.
- Packages are unsigned; Windows SmartScreen and macOS Gatekeeper may warn.
